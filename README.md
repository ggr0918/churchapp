# 교회 헌금 정산기 (v1.2.0)

개교회의 주일 및 각종 예배 헌금 집계, 출석 현황 관리, 주간·월간 결산 보고서 작성, 연말정산용 헌금 기부 확인증 발급을 한 번에 처리할 수 있는 PC 전용 정산 프로그램입니다.

---

## 📥 프로그램 다운로드 및 설치

[Releases 페이지](https://github.com/ggr0918/churchapp/releases/latest)에서 아래 두 가지 방식 중 원하는 파일을 내려받아 실행하세요.

| 구분 | 파일명 | 특징 및 권장 환경 |
| :--- | :--- | :--- |
| **설치 버전 (권장)** | `Setup.1.2.0.exe` | 바탕화면 및 시작 메뉴에 아이콘이 생성되며, 추후 새 버전 출시 시 업데이트 연동에 유리합니다. |
| **무설치 실행 버전** | `1.2.0.zip` | 별도 설치 없이 원하는 폴더(또는 USB)에 압축을 푼 뒤 내부 실행 파일(`.exe`)을 바로 실행합니다. |

> **Windows 보안 경고 창이 뜰 경우:** 처음 실행 시 *"Windows의 PC 보호"* 안내가 나타나면 **[추가 정보]** → **[실행]**을 순서대로 눌러 실행해 주세요.

## ⚙️ 처음 시작하기 (개교회를 위한 초기 3단계 세팅)

프로그램을 처음 설치한 뒤 실제 헌금 입력을 시작하기 전에 아래 3가지를 먼저 설정하면 우리 교회 실정에 맞춰 바로 사용할 수 있습니다.

1. **우리 교회 이름 등록**
   * 우측 상단 **[⚙️ 설정]** → **[⛪ 기본 정보]** 탭에서 교회 이름을 입력하고 **[이름 저장]**을 누릅니다.
   * 입력한 교회 이름은 상단 타이틀, 정산서 인쇄물, 엑셀 보고서, 헌금 기부 확인증 직인란에 자동 반영됩니다.
2. **예배 구분 및 헌금 항목 맞춤 설정**
   * **[⚙️ 설정]** → **[🙏 예배 구분]**: 주일 1·2부, 수요예배, 새벽기도회 등 우리 교회의 예배 목록을 추가하거나 순서를 조정합니다.
   * **[⚙️ 설정]** → **[📋 헌금 항목]**: 십일조, 감사헌금, 주정헌금, 선교헌금, 건축헌금 등 우리 교회에서 사용하는 헌금 종류를 자유롭게 편집합니다.
3. **성도 명부 등록**
   * 상단 두 번째 탭 **[성도 명부 관리]**로 이동합니다.
   * **대량 등록:** **[📥 예시 포함 양식 다운로드]**로 양식(`.xlsx`)을 받아 `성명 / 성별 / 직분`을 채운 뒤 **[명단 엑셀 업로드]** → **[명부 저장하기]**를 누릅니다.
   * **개별 등록:** 상단 입력 칸에 성명·성별·직분을 적고 **[추가]** 후 **[명부 저장하기]**를 누릅니다.

## 📋 주요 기능 안내

### 1. 헌금 정산 입력
* **일자 및 예배 선택:** 상단에서 `정산 일자`와 `예배 구분`을 선택합니다. 이미 기록이 저장된 예배는 목록에 `✅` 표시가 나타나며, **[📅 예배 기록 목록]** 버튼으로 과거 기록을 한눈에 조회·이동할 수 있습니다.
* **명단 불러오기 및 입력:** **[명부에서 선택 불러오기]**로 해당 예배에 헌금·출석한 성도를 체크해 추가하거나 **[빈 행 추가]**로 직접 입력합니다.
* **출석 및 온라인 구분:** 남자/여자 및 주일(대면)/비대면 체크 시 출석 인원이 자동 합산되며, 계좌이체 헌금은 `온라인`에 체크하면 우측 요약 패널에서 **봉투(현금) 합계**와 **온라인(계좌) 합계**가 분리 집계됩니다.
* **저장 및 출력:** 입력 후 **[데이터 안전하게 저장하기]**를 누르고, **[정산서 즉시 인쇄 🖨️]**(재정부·담임목사 결재란 포함) 또는 **[정산서 엑셀 다운로드]**로 보고서를 출력합니다.

### 2. 주간 / 월간 결산
* 조회할 `연월`과 `주차`(`전체 합계` 또는 `1주차(11월1일~7일)` 형태 자동 표기)를 선택하면 기간 내 총 헌금 합계, 온라인 입금 총액, 총 출석 인원, 예배 건수와 항목별 그래프가 자동 산출됩니다.
* **[결산서 인쇄]** 시 1페이지에 월간/주간 요약표가 출력되며, *'인쇄 시 예배 상세 내역 포함'*을 체크하면 2페이지부터 주차별 예배 요약표가 이어서 인쇄됩니다.
* **[엑셀 다운로드]**를 누르면 글자 크기와 여백이 정돈된 결산 보고서 파일(`.xlsx`)이 저장됩니다.

### 3. 헌금 기부 확인증 조회 및 발급
* `귀속 연도`, `성도 이름`, `용도(예: 연말정산용(세무서제출))`를 입력하고 **[확인증 조회]**를 누르면 명부에 등록된 직분과 교회명이 자동 연동된 **헌금 기부 확인증** 양식이 생성됩니다.
* **[확인증 인쇄]**, **[확인증 엑셀 저장]** 외에 개인별 상세 이력이 필요할 경우 **[📊 1년 예배별 헌금 내역 엑셀]** 버튼으로 날짜·예배별 전체 내역을 별도 엑셀로 내려받을 수 있습니다.

## 💾 데이터 백업 및 PC 이전 방법 (필수 권장)

모든 데이터는 사용 중인 PC의 앱 내부 저장소에 보관되므로 **월 1회 이상 백업 파일 저장**을 권장합니다.

* **백업하기:** 우측 상단 **[⚙️ 설정]** → **[💾 백업 / 복원]** → **[💾 전체 데이터 백업 저장]** 클릭 시 `[교회명]_전체데이터백업_YYYY-MM-DD.json` 파일이 다운로드됩니다.
* **복원 및 새 PC 이전:** 새 PC에 프로그램을 설치한 뒤 **[⚙️ 설정]** → **[💾 백업 / 복원]** → **[📂 백업 파일 불러오기]**에서 저장해 둔 `.json` 파일을 선택하면 성도 명부, 전체 헌금 기록, 교회 설정이 그대로 복원됩니다.

## ❓ 자주 묻는 질문 (FAQ)

* **Q. 입력하던 내용을 실수로 지웠어요.**
  * 우측 요약 패널 하단의 **[되돌리기 (복구)]** 버튼을 누르면 직전 저장 상태로 복구할 수 있습니다.
* **Q. 새해가 되어 전년도 헌금 기록만 정리하고 새로 시작하고 싶어요.**
  * 먼저 **[💾 백업 / 복원]**에서 전년도 전체 데이터를 백업 파일로 보관한 뒤, **[⚙️ 설정]** → **[🗑️ 기록 초기화]** 탭에서 기존 헌금 기록만 초기화하면 성도 명부와 예배·헌금 항목 설정은 그대로 유지됩니다.
